3

Lora + Open Sans

Studio pick
Headings: Lora 600 (serif) Body: Open Sans 400 — unchanged 2 families to load

A serif heading changes what the brand sounds like: less app, more clinician. Lora has calligraphic roots but stays sturdy on screen, and it warms up nicely next to your orange while letting the teal read as medical-trustworthy. Body text stays exactly as it is today, so this is the biggest character gain for the smallest change — you'd swap one font picker. Genuine contrast between heading and body is what pairing is actually for.

Archivo + DM Sans

Headings: Archivo 700 Body: DM Sans 400 2 families to load

The athletic direction: Archivo is a compact grotesque that makes headlines feel like performance gear rather than a health pamphlet — a fit if the brand leans toward runners and sport. DM Sans is geometric and crisp at small sizes. The tradeoff: it cools the brand's warmth, and next to the orange it reads more "training app" than "podiatrist-designed."

To apply any of these: Shopify admin → Theme settings → Typography → change the Heading and/or Body font pickers. All four candidates ship in Shopify's font library (search: Figtree, Open Sans, Lora, Archivo, DM Sans). Preview on an unpublished theme first.

What to check before deciding: a full product page (long descriptions), the 14px eyebrow size, prices and the cart. Mockups above use the theme's real scale — H1 56px fluid, H3 32px, body 16px, eyebrow 14px — and real scheme colors (teal #004d72, orange #d45511).

Fonts in this page are embedded Google-hosted equivalents of the Shopify library versions; storefront mockups stay light in dark mode because the store itself is light. Companion doc: docs/design-system.md.
